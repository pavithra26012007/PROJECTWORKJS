PAVITHRA S — PORTFOLIO WEBSITE

Files:
- index.html: website structure and portfolio content
- style.css: styling and responsive layout
- script.js: mobile navigation and current year
- assets/profile.jpg: your single profile photo used on the home section

How to open:
1. Extract the ZIP file.
2. Open the pavithra_portfolio folder.
3. Double-click index.html, or open it with a browser.

To edit:
- Change your details and text in index.html.
- Change colors and layout in style.css.
- Change interactions in script.js.

Note:
This portfolio was created from the uploaded resume. Please check the education year/semester details and course titles before publishing. The portfolio uses a text-based initials illustration rather than a personal photograph.
